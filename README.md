# 1024(草榴论坛) Autoreply - 多用户自动回帖脚本

这是一个针对草榴论坛（1024 / t66y.com）编写的多用户自动回帖脚本，适用于“新手上路”到“侠客”级别的用户，帮助用户通过自动回帖快速积累积分，并且支持自动点赞等功能。

购买草榴邀请码 [联系](https://t.me/honus_chat_bot)

**警告: 使用过程建议多注意更新，否则可能因为草榴社区更改规则造成封号风险。**

## 💡 项目功能分析 (Features)

本项目具备以下核心功能：
1. **多账号支持**：支持配置多个账号并行运行自动回帖（使用多进程处理，账号密码之间使用空格隔开即可）。
2. **两步验证 (2FA) 支持**：支持通过谷歌身份验证器 (Google Authenticator) 密钥自动获取并输入验证码进行登录。
3. **Cookie 会话保持**：自动保存登录状态到本地 Cookie 文件，避免频繁进行密码和验证码登录。
4. **自动验证码识别**：支持对接打码平台 (如 apitruecaptcha, ttshitu) 自动识别登录验证码，或配置为手动输入验证码。
5. **智能避让版主**：可配置自动过滤版主发布的帖子，防止因为误回复版主被封禁。
6. **自动点赞**：支持每日自动点赞一次，增加活跃度。
7. **支持 GitHub Actions**：可利用 GitHub Actions 实现云端定时自动化运行，无需自己准备服务器。
8. **自定义回复内容与延迟**：内置多条随机回复话术，并可配置 1024~2048 秒的随机休眠时间以模拟真人操作。

## ⚙️ 配置文件 (config.py)
在 `config.py` 中可以进行如下基础配置：
```python
config={
    'Forbid':  True,              # True为屏蔽版主发帖，无参数或者False为不屏蔽
    'Input_self':  False,         # 设置为True为手动输入验证码，无参数或者False为自动输入
    'like': True,                 # True为每日自动点赞一次，无参数默认为True
}
```

## 🚀 使用说明

### 方式一：使用 GitHub Actions (推荐)

无需自己的服务器，白嫖 GitHub 运行。

1. **Fork 本仓库** 到你自己的 GitHub 账号下。
2. 进入你 Fork 的仓库，点击 `Settings` -> `Secrets and variables` -> `Actions` -> `New repository secret` 添加以下环境变量：

   **必需参数 (多个账号请用空格隔开，保证三个参数的账号顺序一致):**
   * `USER`: 用户名
   * `PASSWORD`: 密码
   * `SECRET`: 谷歌身份验证器密钥

   **可选参数 (用于自动识别验证码，任选其一配置即可，不配置若遇到验证码可能会失败):**
   * **方式A: TrueCaptcha (每日免费 100 次)** - [申请地址](https://apitruecaptcha.org/)
     * `USERID`: api页面中的 userid 字段
     * `APIKEY`: api页面中的 apikey 字段
   * **方式B: 某打码平台 (付费，1元500次)** - [注册地址](http://ttshitu.com/register.html?inviter=3d92d1b2371f487d9072430a93bb043c)
     * `CODEUSER`: 注册用户名
     * `CODEPASS`: 注册密码

3. 如果要更改打码平台，可以在 `1024.py` 中修改调用 `GetVerificationCode` 的相关代码（默认配置可不改）。
4. 点击仓库顶部的 `Actions`，同意使用协议。
5. 在左侧菜单点击 `1024-AutoReply`，然后点击右侧的 `Run workflow` 即可手动触发执行一次。（之后等待 GitHub Actions 定时自动执行即可）。

**注意**: Actions 每次运行最大时间限制为 6 小时，所以自定义随机休眠时间建议控制在 `1024-2048` 之间。如果运行超时，请调小休眠时间或者检查之前的回帖状态。

### 方式二：本地运行

如果你想在本地机器或自己的服务器上运行：

1. 克隆本仓库到本地。
2. 安装依赖 (如果尚未安装，可根据需要安装 `requests`, `onetimepass`, `Pillow` 等库)。
3. 在运行环境中设置环境变量，或者直接在运行脚本前通过命令行传入参数（多个账号用空格隔开）：
   ```bash
   export USER="username1 username2"
   export PASSWORD="password1 password2"
   export SECRET="secret1 secret2"
   ```
4. 如果配置了打码平台，也需配置相应的打码平台环境变量。
5. 运行脚本：
   ```bash
   python 1024.py
   ```
   **进阶玩法**：有能力的同学可自行抓包，利用现有的 Cookies 文件直接登录，跳过验证码环节。
